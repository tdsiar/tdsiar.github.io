The Morning Paper

Python, Claude, headless Chrome · Jul 2026 to Sep 2026 · source on GitHub (MIT)

What it is

A newspaper for one reader. Every morning it reads only the sources I chose (blogs, YouTube channels, podcasts), has Claude edit them into a broadsheet with a front page and one section per source worth reading, and produces a PDF to print or read with coffee. If nothing good happened, it says so. I built it to replace scrolling YouTube and X.

How it works

  1. Schedule. A macOS launchd job starts the run at a set time each morning.
  2. Fetch. The fetcher reads each source's feed. A SQLite store remembers what was already printed, so nothing repeats.
  3. Edit. The editor sends the new items to Claude through the Claude Code command line in a sealed mode: no tools, no MCP servers, no user settings, and an empty temporary working folder. The model can write text but cannot read or change anything on the machine.
  4. Typeset. The Markdown result becomes HTML. A sanitizer and a content security policy block all scripts, because the text comes from the internet and from a model. Headless Chrome prints the HTML to PDF.
  5. Deliver. The PDF goes to the printer, to email, or to an archive.

To make it usable by other people, I added a setup wizard, a tool that turns a YouTube page or podcast name into a verified feed, an install script, and a security page that lists everything that touches the network. It has 123 automated tests.

Where it stands

It made 55 editions between July 10 and September 23, 2026. On September 23 the editor call timed out three times and the paper fell back to a plain edition. It has been paused since then.

What I learned

  • To treat a model's output like any untrusted input: limit what it can touch, and sanitize what it returns.
  • To check that the output exists, not just the exit code. One Chrome flag made PDF printing exit successfully while writing no file.
  • That shipping for other people is its own job: defaults, privacy, install, and docs.
